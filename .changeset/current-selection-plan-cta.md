'pricing-renderer': minor
---

`<pricing-renderer>` can show the customer's current subscription. The new property `currentSelection` (type `Partial<PricingSelection>`, no attribute, also a React prop) marks the current plan card with `data-current="true"` and a "Your plan" badge, turns its CTA into a disabled "Current plan" button, labels the other plans' CTAs "Upgrade to {plan}" or "Downgrade to {plan}" by the declaration order of the plans (private plans included, even when `visibility` hides their cards), uses "Contact sales" for a plan without a price amount, marks the current add-ons with a "Current" badge, and adds a summary button ("Review change ({total})", or "Contact sales" when the selection needs a quote) that is disabled while the selection equals the current one. The element keeps a deep copy, never writes it into the selection in effect and emits no `pricing-selection-change`. An unknown plan or add-on id marks nothing and is reported once per change in a `pricing-diagnostic` event with `PR_CURRENT_SELECTION_UNKNOWN_PLAN` or `PR_CURRENT_SELECTION_UNKNOWN_ADDON`. The new property `pendingActionId` (attribute `pending-action-id`, also a React prop) shows a busy state on the CTA with that action id and disables the other CTAs with `aria-disabled`, so activating them emits no `pricing-action`. `pricing-action` details gain the optional `relation` and `source` fields while the current plan is known, and `SelectionRelation` is re-exported from `pricing-renderer/element` and `pricing-renderer/react`. `PricingCta` gains `labels` (`upgrade`, `downgrade`, `current`, `contactSales`; `PricingCtaLabels`). New part hooks: `current-badge`, `current-add-on-badge`, `summary-action` and `cta-pending`. Seven new message keys exist in `en-US` and `es-ES`. Behavior change: in the `href` of a plan CTA, every `{planId}` is now replaced with the encoded plan id before the link is checked, so an `href` that contains that literal text changes. Without `currentSelection` and `pendingActionId` the markup, labels and events are the same as before.
