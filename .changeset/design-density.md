New opt-in `density` attribute, property and React prop (`'comfortable' | 'compact'`). `compact` tightens the spacing tokens (`--pr-space-1` to `--pr-space-5`, `--pr-space-section` and `--pr-shell-padding`) for dense host layouts. The default is `comfortable` and renders as before; any other value reads as `comfortable`.
