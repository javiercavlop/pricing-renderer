Make complete plan and add-on cards selectable with larger accessible visual
indicators, and add project initialization defaults for an English locale and
the configurable `/pricing` application path. Project and instance configuration
can independently disable plan/add-on selection, CTAs, and interactive variable
editing while keeping all three enabled by default. Add typed feature/usage-limit
card highlights with auto, manual, and hybrid modes; conservatively verified
“Everything in…, plus” inheritance; and optional configurable plan badges that
can visually emphasize a card. Presentation can be supplied from project
configuration, per-instance props, or `custom.pricingRenderer`.
