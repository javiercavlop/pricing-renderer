# Visual baselines

The `-linux` visual baselines in `tests/browser/pricing-renderer.spec.ts-snapshots` were regenerated by a one-off CI run. That run used a temporary workflow that is not part of this branch. It rendered the stylesheet of head `9d0b8b4` of this branch.

The review fixes of that head change nothing in the demo page pixels.

The macOS baselines (no `-linux` suffix) are not regenerated in CI. They stay stale until someone with macOS updates them on purpose.

Before the pull request is marked ready, inspect each regenerated PNG against its previous version (see the git history of the snapshots folder).
